# Краткая дорожная карта TCD

## Развёрнутая основа

- PR #16 — список VODs.
- PR #17 — превью конечных результатов.
- PR #18 — непосредственный выбор готового результата.
- PR #19 — превью карточек и текущие названия действий.
- PR #20 — прогресс и восстановление после отмены из списка.
- PR #21 — уведомления устаревших кнопок; объединён и развёрнут в production.

## В разработке

Корректирующий PR: единый переход «список VODs ↔ карточка VOD» независимо
от готовности HTML и единое немодальное уведомление «Кнопка больше неактуальна».
Реализовано в ветке PR; ожидает review, merge и отдельного deployment.

## Следующая задача

После подтверждённой отмены по прямой ссылке/VOD ID возвращать карточку VOD:
информационную с превью и обработкой при отсутствии результата либо предложение
готового чата с получением/повторной обработкой. Без искусственного списка и
«Вернуться к списку», только после очистки операции и освобождения слота.

## Следующий крупный этап

Отправка существующего HTML-файла прямо в Telegram без повторной генерации:
лимиты размера, безопасные local/public пути, экономия RAM/диска Oracle,
понятное имя файла, защита от повторных запросов и ошибок отправки.

## Последующая переработка UI

Сократить переходы готовых VODs: непосредственное открытие чата из карточки,
отдельное получение файла; рассмотреть «Обработать чат», «Обработать чат заново»,
«🌐 Открыть чат», «📄 Получить файл». Убрать избыточный текст, включая «Чат VOD
уже готов», когда состояние очевидно. Унифицировать карточки списка и прямых
ссылок, сохранив правильный момент записи в историю при сокращении экранов.

## Отложено

- Сравнить качество и размеры превью перед повышением с 480×270 до 720×405.
- Компактный `/start` и возможное использование Telegram Menu.
- Mini App — только при отдельном обосновании.
- Не скрывать «изменено» рискованными удалениями/переотправками.

Это план следующих согласований, а не разрешение реализовывать их в текущем PR.
Исторический [ROADMAP.md](../ROADMAP.md) сохраняется отдельно.
