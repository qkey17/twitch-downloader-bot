## Ближайшие исправления HTML

- **Открытие HTML и ссылки.** Экран загрузки до первой порции чата, карточки Twitch-клипов из Helix и подтверждение перехода по внешним ссылкам.
- **Отложено.** Тёмная полоса и рывки анимации в конце чата во встроенном просмотрщике Telegram Android. По наблюдению владельца, в обычном Chrome на том же смартфоне дефект не воспроизводится. Дополнительная диагностика отложена.
- **Локализация уведомлений Twitch.** После получения от владельца точных официальных русских формулировок.

- **Мобильная шкала.** Повторные запросы к одному краю шкалы подавляются во время ожидания и выполнения перехода. Обратное движение сразу меняет цель. Связь повторных переходов с тёмной полосой в состоянии `OFFLINE` остаётся гипотезой до проверки на физическом смартфоне.

- **Интерактивность HTML-чата.** PR #87 добавил подсветку распознанных @-упоминаний, закрепление всей строки и рамку списка. [Deployment](https://github.com/qkey17/twitch-downloader-bot/actions/runs/43312711837).
- **Выбор сообщения и кадра.** PR #89 привязал автоматический выбор к верхней границе чата и вернул цельную десктопную панель. [Deployment](https://github.com/qkey17/twitch-downloader-bot/actions/runs/43417404160).
- **Шкала и превью.** PR #90 выпустил крайние положения шкалы, обратную догоняющую привязку, OFFLINE и свёрнутое при загрузке десктопное превью. [Deployment](https://github.com/qkey17/twitch-downloader-bot/actions/runs/43430098357).
- **Мобильный конец чата.** Во время раскрытия и сворачивания панели в физическом конце список сохраняет положение. Резерв под панель и нижний якорь обновляются вместе по завершении перехода. Остаются только боковые границы, шкала показывает `OFFLINE` без длительности. Поведение системной панели и скруглённого экрана на физическом смартфоне требует ручной проверки.
- **Совместимость Twitch storyboard.** Для двух VOD asasnow подтверждены доступные атласы high. TCD учитывает округлённый интервал из manifest и выбирает только кадры с отметками внутри длительности VOD.
- **Категории эмоутов.** Отображать отдельно все достоверно известные группы. Оставить `Other Emotes` для случаев, где категорию установить не удалось.
- **В текущем PR.** Распознавать Unicode-упоминания по отображаемому имени и по Twitch login. Показывать `Other Emotes` для подтверждённых подписочных эмоутов Twitch. Изменения применяются к новым HTML после выпуска.
- **Кликабельные ссылки.** В текущем PR добавлены обычные HTTP/HTTPS-ссылки, включая ссылки на клипы, записи и каналы Twitch. Изменение применяется к новым HTML после выпуска.

## Функциональное развитие

- **Хранение HTML.** Один VOD — одна актуальная успешно подготовленная версия с постоянным случайным именем, назначенным при первой обработке. Переобработка атомарно заменяет содержимое по тому же адресу и сохраняет рабочую версию при сбое. Новые Telegram-карточки, callback, кеш, история, просмотр и скачивание обращаются к актуальной версии. Поддержка старых карточек при миграции необязательна. Очистка дубликатов проводится отдельно после определения сохраняемых файлов. Если метаданных недостаточно, владелец предоставит ссылки на обязательные к сохранению чаты.

- **Отложено для ПК.** Полоса прогресса в десктопном чате остаётся идеей без плана реализации.
- **Полностью автономный HTML.** Отложена идея встраивать только эмоуты и бейджи, реально использованные в чате. Сначала оценить размер файлов, поддержку анимации, RAM, производительность браузера и историческую точность распознавания эмоутов.
- **Исследование качества кадров.** Отдельно оценить получение кадров из видео с учётом размера и нагрузки. Реализация пока не запланирована.
- **Мобильные устройства.** Проверить и реализовать выделение целых сообщений и диапазонов для действий «Скриншот» и «Копировать». Использовать логические индексы, чтобы диапазон работал за пределами видимого окна большого чата. Согласовать долгое нажатие со стандартным выделением текста, ссылками, эмоутами, бейджами и контекстными окнами. Сохранять кнопку «Снимок» до принятия полноценной замены на реальном телефоне.
- **Обязательная функция Premium.** Постоянные подписки на Twitch-каналы с автоматическим отслеживанием новых завершённых публичных VODs. Учитывать задержку публикации, ставить VOD в существующую очередь только один раз и доставлять готовый чат всем подписчикам. Ограничивать нагрузку на Oracle.
- **Готовые результаты в Telegram.** Сокращать лишние переходы и текст в карточках, сохраняя доступ к истории и скачиванию. Отдельно остаётся ручная проверка доставки HTML и поведения при недоступном превью. Компактный `/start` и Telegram Menu остаются отложенными.
- **Большие HTML.** Виртуализация и компактный формат уже выпущены. Разбор JSON, расход памяти браузера и доставка online HTML остаются ограничениями. Нативный scrollbar Android отдельно не меняется.

## Исследования и необязательные идеи

- **Неопубликованные VODs.** Проверить штатный доступ к истории чата сохранённой, но неопубликованной записи при разрешении владельца канала. Отдельно учитывать случай, когда запись вообще не сохранялась.
- **LIVE-сборщик.** Оценить ограниченный пилот Twitch EventSub без скачивания видео, с дисковым буфером и лимитами. История до подключения и сообщения в разрывах не гарантируются.
- **Ссылки Twitch Clips.** Twitch поддерживает штатный шаринг клипов, каналов и записей, включая таймкод записи. Внешнее встраивание клипов и видео описано отдельно. Превью ссылок в чате документировано у расширения FrankerFaceZ. Актуальное штатное превью для вставленных URL в чате Twitch официальные материалы не подтверждают. Превью в TCD рассматривать при подтверждённой пользе и допустимых расходах. [Справка Twitch](https://help.twitch.tv/s/article/how-to-share-a-stream) · [Встраивание Twitch](https://dev.twitch.tv/docs/embed/video-and-clips/) · [FrankerFaceZ](https://docs.frankerfacez.com/dev/link-preview/).
- **Telegram HTML Widgets.** Оценить небольшой виджет состояния или прогресса VOD вне production TCD. Отдельный Telegram Widget Lab для создания и проверки виджетов — необязательная идея. Сохранить HTML-просмотрщик отдельным и менять действующий Telegram UI только при доказанной пользе. [Bot API 10.4](https://core.telegram.org/bots/api-changelog#november-9-2026).
- **Local Bot API.** [Подготовка сборки и инструкция](local-bot-api.md) выпущены. [PR #27](https://github.com/qkey17/twitch-downloader-bot/pull/27) остаётся отдельным решением. Для перехода с Cloud нужны отдельное согласование, план возврата, проверки прав, ресурсов Oracle и лимитов backup/offsite. Cloud поддерживает отправку готовых HTML до 40 MiB.
- **Twitch pagination.** Диагностика и экспериментальное восстановление из PR #28/#29 остаются выключенными. Полнота всего чата не доказана. Новые эксперименты требуют отдельного решения.
- **Отдалённые идеи.** Дополнительная карточка пользователя при нажатии на никнейм и Mini App остаются необязательными.

Корневой [ROADMAP.md](../ROADMAP.md) хранит исторический план.
