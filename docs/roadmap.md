## Следующий крупный этап

После стабильного отдельно согласованного перехода на Local Bot API — отправка
существующего HTML-файла прямо в Telegram без повторной генерации:
лимиты размера, безопасные local/public пути, экономия RAM/диска Oracle,
понятное имя файла, защита от повторных запросов и ошибок отправки.
Offsite budget 1,5 млрд байт требует отдельного решения для больших HTML;
нынешние backup/recovery и их лимиты не изменяются подготовительными этапами.

## Последующая переработка UI

Сократить переходы готовых VODs: непосредственное открытие чата из карточки,
отдельное получение файла; рассмотреть «Обработать чат», «Обработать чат заново»,
«🌐 Открыть чат», «📄 Получить файл». Убрать избыточный текст, включая «Чат VOD
уже готов», когда состояние очевидно. Унифицировать карточки списка и прямых
ссылок, сохранив правильный момент записи в историю при сокращении экранов.
